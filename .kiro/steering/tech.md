# Technology Stack

## Frontend Technologies
- **HTML5**: Semantic markup with proper meta tags and SEO optimization
- **CSS3**: Custom styling with modern features and animations
- **JavaScript (ES6+)**: Interactive functionality and DOM manipulation
- **Bootstrap 5**: Responsive grid system and UI components

## Libraries & Frameworks
- **TypeIt.js**: Text typing animation effects
- **Particles.js**: Interactive particle background animations
- **Bootstrap Bundle**: Complete Bootstrap JavaScript components
- **Google Fonts**: Nunito and Nunito Sans font families

## Styling Approach
- **Custom CSS**: Primary styling in `css/style.css`
- **Bootstrap CSS**: Framework styles via CDN
- **Responsive Design**: Mobile-first approach with Bootstrap grid
- **Color Scheme**: Dark theme (#1e1e28 background, #ffc107 accent)
- **Typography**: Nunito font family for consistent branding

## Build System
This is a static website with no build process required. Files are served directly.

## Development Workflow
- **No compilation needed**: Direct HTML/CSS/JS editing
- **Live reload**: Use any local server for development
- **Testing**: Open `index.html` in browser for immediate preview

## Common Commands
```bash
# Serve locally (Python)
python -m http.server 8000

# Serve locally (Node.js)
npx serve .

# Serve locally (PHP)
php -S localhost:8000
```
